# 버스 도착 알리미: 작업 정리

작성일: 2026-11-25 (지하철 앱 `D:\Trans\docs\프로젝트_정리.md`를 바탕으로 만듦)

## 1. 앱 개요
- 서울 버스 정류소를 고르면 노선별로 **1시간 안에 오는 버스**를 보여주는 휴대폰 웹앱(PWA)
- 사용 흐름: (이름 검색 또는 📍 지도에서 주변 정류소 선택) → 정류소 도착 화면 → 필요하면 노선 하나만 선택
- 지하철 앱과 같은 기능: 자주 가는 항목 6개(정류소+노선), ⚙ 설정(아이콘 사진 변경, 홈 화면 설치, 자주 가는 정류소), ? 사용 방법, 뒤로가기, 다크 모드

## 2. 지하철 앱에서 바뀐 점
| 지하철 | 버스 |
|---|---|
| 역 → 호선 선택(필수) | 정류소 → 노선 선택(선택, 기본은 전체) |
| 상행/하행 2열 | 노선 카드마다 다음 버스 2대를 2열로 |
| 실시간 + 시간표 | 실시간만 (버스는 노선마다 다음 2대만 줌) |
| `lib/seoul.js` | `lib/bus.js` + 예시 데이터 `lib/mock.js` |
| localStorage `subway.*` | `bus.favs`, `bus.icon` |
| 검색만 | 검색 + **네이버 지도 주변 정류소** (`/api/nearby`) |

## 3. 정류소 방향 문제 해결
- 같은 이름 정류소가 길 양쪽에 따로 있음 → 정류소 번호(arsId)를 항상 함께 표시
- 도착정보의 `nxtStn`(다음 정류장) 중 가장 많은 값을 **"→ ○○ 방면"** 으로 표시 (도착 화면, 지도 선택 카드, 자주 가는 정류소)
- 검색 결과에 같은 이름이 여러 개면 "길 건너편 있음" 표시, 📍로 지도에서 위치 확인

## 4. 데이터 처리
- `arrmsg1/2` ("5분12초후[3번째 전]", "곧 도착", "운행종료", "출발대기") + `traTime1/2`(초) → 남은 초
- `mkTm`(데이터 생성 시각, 한국 시간) 기준으로 지난 시간만큼 빼서 보정
- 혼잡도: `rerdie_Div=4`일 때 `reride_Num` 3 여유 / 4 보통 / 5 혼잡, 저상 `busType=1`, 막차 `isLast=1`
- 노선 색: `routeType` (3 간선 파랑, 4 지선 초록, 5 순환 노랑, 6 광역 빨강, 2 마을, 1 공항, N으로 시작하면 심야)
- 키 형식: 공공데이터포털 키에 `%`가 있으면(Encoding) 그대로, 아니면(Decoding) 인코딩해서 붙임
- 2026-11-25 실제 키로 확인 완료: 필드 이름(`rerdie_Div`, `reride_Num`, `busType`, `nxtStn`, `adirection`) 모두 맞음

## 5. 지도
- 네이버 지도 v3 (`oapi.map.naver.com/openapi/v3/maps.js?ncpKeyId=`). 처음 지도 버튼을 누를 때만 불러옴
- 내 위치: `navigator.geolocation` (https 또는 localhost에서만). 거부되면 서울시청 주변
- 주변 정류소는 반경 500m, 좌표를 소수 셋째 자리(약 100m)로 반올림해서 하루 캐시 → 호출 횟수 절약
- 지도를 250m 넘게 옮기면 "↻ 이 지역에서 다시 찾기" 버튼
- 키가 없거나 인증 실패면 지도 없이 가까운 정류소 목록만 보여줌
- 네이버 지도는 지도 영역(#map)에 `position:relative`를 직접 넣음 → `position:absolute; inset:0`로 크기를 잡으면 높이가 0이 됨. width/height 100%로 지정
- Web 서비스 URL은 포트까지 구분함 (localhost:3000만 등록하면 3001에서는 인증 실패 / 500 오류)
- 핀을 누르면 아래 패널을 맨 위로 올려서 "이 정류소 버스 보기" 카드가 바로 보이게 함

## 6. 배포 상태 (2026-11-25)
- GitHub: https://github.com/Brian-Yoo/bus, 배포: https://bus-three-xi.vercel.app (Vercel 팀 trans, 프로젝트 bus)
- 환경변수: `BUS_API_KEY`, `NAVER_MAP_CLIENT_ID`, `BLOB_STORE_ID`(자동)
- Blob 저장소 `bus-icons`(비공개) 연결, 배포 사이트에서 사진 아이콘 업로드 확인
- 배포 사이트에서 검색·주변 정류소·도착정보·네이버 지도 모두 실제 데이터로 확인

## 7. 이번에 겪은 문제와 해결
| 문제 | 해결 |
|---|---|
| 처음엔 30분 이내만 표시 | 1시간으로 변경 (WINDOW_MIN / WINDOW_SEC) |
| 지도 영역 높이가 0 (빈 화면) | 네이버 지도가 #map에 position:relative를 넣음 → width/height 100%로 지정 |
| 핀을 누르면 "이 정류소 보기" 카드가 목록에 밀려 안 보임 | 선택 시 아래 패널을 맨 위로 스크롤 |
| 지도 키를 넣어도 "키 없음"으로 나옴 | `/api/config`가 브라우저에 5분 캐시됨 → 캐시 금지 + `cache:'no-store'` |
| localhost:3001에서 지도 인증 500 오류 | 네이버 Web 서비스 URL은 포트까지 구분 → 3001도 등록 |
| Vercel 가져오기 목록에 bus 저장소가 안 보임 | Configure GitHub App에서 bus 저장소 접근 허용 |
| Vercel이 Preset을 Node로 자동 선택 | Other로 변경 (vercel.json이 설정 담당) |
| 휴대폰(Remote Control)에서 "Deploy 눌렀어" 했는데 배포 안 됨 | 앱 안 브라우저 패널은 PC에만 있음 → PC 브라우저에서 직접 진행 |
| Blob 연결 메뉴(Connect Project)를 못 찾음 | 프로젝트 화면의 Storage에서 만들면 자동 연결됨. 다른 저장소 연결은 Storage → Connect Database |
| 이 PC에 gh CLI 없음 | 저장소는 github.com/new 에서 만들고 git push는 Windows 자격 증명으로 |
