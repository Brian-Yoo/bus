        자주 가는 정류소

        처음 화면에 바로가기로 표시됩니다. 최대 6개.

          ②
          볼 노선을 고르세요 (전체도 가능)

          6개가 모두 찼어요. 아래 목록에서 하나를 지우면 추가할 수 있어요.

            사용 방법

            🚏 정류소 찾기

            같은 이름의 정류소가 길 양쪽에 따로 있어요. → 다음 정류장 방면과 정류소 번호(5자리)를 보고 고르세요.

            방법 1. 지도에서 고르기 (추천)

            1. 검색창 옆 📍 지도를 누릅니다.
            2. 위치 권한을 허용하면 내 위치(파란 점)와 주변 정류소가 보입니다.
            3. 정류소 핀이나 아래 목록을 누르면 방향과 노선이 나오고, 이 정류소 보기를 누릅니다.
            4. 지도를 옮긴 뒤 ↻ 이 지역에서 다시 찾기로 다른 곳도 찾을 수 있어요.

            방법 2. 이름으로 검색

            1. 위 검색창에 정류소 이름(예: 강남역)이나 번호(예: 22009)를 입력합니다.
            2. 결과 오른쪽 📍를 누르면 지도에서 위치를 확인할 수 있어요.

            🚌 도착 화면 보는 법

            1. 노선마다 다음 버스 2대 중 1시간 안에 오는 버스를 보여줍니다.
            2. 위쪽 노선 버튼으로 한 노선만 골라 볼 수 있어요.
            3. 30초마다 자동으로 새로고침됩니다.

            📲 홈 화면에 앱 설치

            설치하면 바탕화면 아이콘으로 앱처럼 바로 열 수 있어요.

            안드로이드 (Chrome)

            1. ⚙ 설정 → 홈 화면에 아이콘 추가 버튼을 누릅니다.
            2. 버튼이 없으면 Chrome 오른쪽 위 ⋮ → 홈 화면에 추가(또는 앱 설치)를 누릅니다.

            삼성 인터넷

            1. 아래쪽 ≡ 메뉴 → 현재 페이지 추가 → 홈 화면을 누릅니다.

            아이폰 (Safari)

            1. 아래쪽 공유 버튼(□↑)을 누릅니다.
            2. 홈 화면에 추가 → 추가를 누릅니다.

            아이콘을 내 사진으로 바꾸고 싶으면 ⚙ 설정 → 아이콘 이미지 변경을 먼저 한 뒤 설치하세요. 이미 설치했다면 아이콘을 지우고 다시 추가해야 바뀝니다.

            ⭐ 자주 가는 정류소 설정

            최대 6개까지 저장하면 첫 화면에서 한 번에 열 수 있어요.

            방법 1. 설정에서 추가

            1. 오른쪽 위 ⚙ 를 누릅니다.
            2. 자주 가는 정류소에서 ① 이름 검색 또는 📍 지도로 정류소 선택 → ② 노선 선택(전체 가능) → ③ 저장.
            3. 목록의 ▲ ▼ 로 순서를 바꾸고, ✕ 로 지웁니다.

            방법 2. 도착 화면에서 바로 저장

            1. 정류소를 열고, 필요하면 노선을 고릅니다.
            2. 정류소 이름 옆 ☆ 를 누르면 ★ 로 바뀌며 저장됩니다.
